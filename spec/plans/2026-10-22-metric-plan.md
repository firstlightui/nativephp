# Metric implementation plan

Date: 2026-10-22

Design: [Tipoff gaps](../designs/2026-10-22-tipoff-gaps-design.md).

1. Write failing PHP publication tests for required strings, optional detail/tone,
   accessibility, no interaction/model, and the real Blade registration seam.
2. Scaffold Metric, then implement strict EDGE publication and paired native static
   text renderers. Reuse semantic theme colours, not generic layout controls.
3. Prove grouped accessibility and full long values at large text; reconcile from
   current server nodes without emitting events.
4. Add stable showcase and capture routes, public reference, maintained contract,
   index and screenshot manifest entries. Run consumer and package tests.
5. With authorized native targets, build both hosts, inspect light/dark and largest
   text captures, and record honest accessibility evidence. Missing native evidence
   blocks release readiness, not reporting development work accurately.
